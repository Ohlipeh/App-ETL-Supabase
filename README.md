## 🛠️ Tecnologias Utilizadas

- 🧩 **Arquitetura:** MVC  
- ⚡ **Motor de Processamento:** Python + Pandas  
- 🎨 **Interface Gráfica (UI):** CustomTkinter  
- 🗄️ **Persistência e Conexão:** Supabase + SQLAlchemy  

---

## ⚙️ Como Executar o Projeto

1. 📂 Extraia o arquivo compactado recebido para uma pasta local no seu computador.  
2. 📝 Renomeie o arquivo `.env.example` apagando a extensão final, deixando apenas `.env`.  
3. 🔑 Configure o arquivo `.env` abrindo-o em um editor de texto simples (como o Bloco de Notas) e insira as credenciais reais do seu banco de dados:
   - Host  
   - Porta  
   - Banco  
   - Usuário  
   - Senha  
4. ▶️ Execute o arquivo `main.exe` com um duplo clique para iniciar a ferramenta.
